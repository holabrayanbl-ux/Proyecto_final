Simulador de Abastecimiento, Precios y Consumo Familiar

Herramienta educativa que permite modelar matemáticamente situaciones reales relacionadas con abastecimiento, transporte, inflación y consumo familiar mediante simulaciones dinámicas.

🎯 Objetivo del Proyecto

Este proyecto tiene como finalidad representar situaciones económicas y sociales del contexto actual mediante modelos matemáticos sencillos, permitiendo visualizar cómo afectan el consumo, los precios, el transporte y el abastecimiento.

📌 Contexto del Problema

En escenarios de inflación, bloqueos, dificultades logísticas o escasez, las familias deben adaptar sus decisiones económicas constantemente.

Este simulador permite analizar diferentes escenarios para comprender mejor el impacto de estas variables sobre el presupuesto, abastecimiento y consumo.
